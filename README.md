# 東京ビッグサイト イベント案内AI
<img width="1256" height="636" alt="TBS_SearchAI01" src="https://github.com/user-attachments/assets/600643b8-7ddd-4dc1-8851-7be76e7f806b" />
miibo（会話AI）とRAG検索を組み合わせた、展示会・イベント検索インターフェースです。  
来場者がチャットで質問すると、ナレッジデータストアからイベント情報を検索し、カード形式で表示します。

## 概要

| 項目 | 内容 |
|------|------|
| 使用AI | [miibo（mebo）](https://miibo.jp/) |
| 検索方式 | RAG（ナレッジデータストア） |
| フロントエンド | Vanilla JS + 素のCSS |
| デプロイ | Vercel（サーバーレス関数でAPIキー管理） |

## バージョンについて

このプロジェクトにはローカル版とVercel版の2種類があります。

| | ver_local | ver_vercel |
|---|---|---|
| 用途 | 動作確認・開発用 | 本番公開用 |
| APIキー管理 | `js/api_id.js` に直接記述 | Vercel環境変数で管理 |
| 起動方法 | VSCode Live Server | Vercelにデプロイ |
| APIキーの露出 | あり（ブラウザから見える） | なし（サーバーレス関数で隠蔽） |

**基本的な流れ：** `ver_local` でローカル動作確認 → 問題なければ `ver_vercel` をVercelにデプロイ

## セットアップ手順

### 1. miibo管理画面の設定

以下の4ステップで設定します。

1. **ナレッジデータストアにCSVを登録**  

2. **エージェントにデータストアを紐付ける**

3. **システムプロンプトをmiiboのプロンプト内に設定する**  

4. **APIキーとエージェントIDを取得する**

---

### 2-A. ローカルで動作確認する場合（ver_local）

`ver_local/js/api_id.js` を開き、APIキーを書き換えます。

```js
const MEBO_API_KEY  = "あなたのAPIキー";
const MEBO_AGENT_ID = "あなたのエージェントID";
```

VSCode の **Live Server** で `ver_local/index.html` を開いて動作確認します。

---

### 2-B. Vercelにデプロイする場合（ver_vercel）

`ver_vercel/` ディレクトリをGitHubリポジトリのルートとしてVercelに接続します。

Vercelダッシュボード → **Settings → Environment Variables** に以下を追加します。

| 変数名 | 値 |
|--------|-----|
| `MEBO_API_KEY` | miiboのAPIキー |
| `MEBO_AGENT_ID` | miiboのエージェントID |

APIキーはサーバーレス関数（`api/chat.js`）で処理され、フロントエンドには露出しません。

## Extension（構造化データ）仕様

miiboのレスポンスにはテキストの他に、以下のJSON形式のExtensionブロックが含まれます。  
`script.js` がこれを解析してイベントカードとして描画します。

````
```extension
{
  "type": "show_events",
  "events": [
    {
      "name":        "展示会名",
      "period":      "4/8（水）〜 4/10（金）",
      "venue":       "東1-3ホール",
      "target":      "一般・商談",
      "admission":   "無料（要登録）",
      "description": "イベントの概要説明",
      "sub_events":  ["同時開催の専門展1", "同時開催の専門展2"],
      "url":         "https://example.com"
    }
  ],
  "followups": ["一般向けを探す", "IT・DX系", "ファッション系"]
}
```
````

| フィールド | 説明 |
|-----------|------|
| `events` | イベントカードの配列（最大5件） |
| `sub_events` | 同時開催・専門展のリスト。なければ `[]` |
| `followups` | クイックリプライボタンのテキスト（2〜3件） |

## ナレッジデータストアについて

### イベントデータの入手方法

東京ビッグサイトのイベントデータは以下の東京都オープンデータカタログサイトからダウンロードしてください。

[https://catalog.data.metro.tokyo.lg.jp/dataset/t001001d0000000001](https://catalog.data.metro.tokyo.lg.jp/dataset/t001001d0000000001)

ダウンロードしたデータをCSVにする場合、miibo用フォーマットに変換してから登録します。

### miibo用CSVフォーマット

miibo のナレッジデータストアは以下のフォーマットのCSVのみ受け付けます。

```
label, url, text
```

- 元データ（n件）を会期・会場でグループ化してn件に圧縮しています
- 圧縮ルール：`（内）` 表記の子イベントは親イベントに統合し、同会場・同会期のイベントもまとめています
